# Cozy Match-3

Match-3 на Unity WebGL, портретная ориентация 9:16: полное ядро поля/матчей/гравитации, четыре
бустера со всеми комбинациями, расширяемые ящики, цели уровня, 12 уровней и экранная панель читов.

*English version: [README.md](README.md)*

## Стек

Unity **6000.3.21f1** · WebGL · URP · uGUI · Zenject · UniTask · R3 1.3.1 (NuGet core) · DOTween ·
New Input System · Unity Test Framework.

## Как запустить

1. Открыть `match3-test/` в Unity 6000.3.21f1.
2. Открыть `Assets/Game/Scenes/Boot.unity` и нажать Play (`Boot` поднимает окружение и грузит `Game`).
3. WebGL-билд: обе сцены уже в Build Settings; кастомный WebGL-шаблон отвечает за леттербокс 9:16 и
   потолок буфера 1080×1920.

Читы собираются под дефайном `MATCH3_CHEATS` (включён для редактора и development-билдов). Сборка
`Match3.Cheats` объявляет `defineConstraints: ["MATCH3_CHEATS"]`, поэтому без дефайна она вообще не
компилируется в билд.

## Что реализовано

- **Основной цикл** — проверка свапа, матчи, урон по препятствиям, очистка, гравитация с диагональным
  скольжением, refill из спавнеров, каскады (автоматчи при опадании), перемешивание при отсутствии
  ходов, подсказка по простою, бонус за остаток ходов при победе.
- **Бустеры** — ракета (матч из 4), бомба (матч углом/буквой Т), радужный шар (матч из 5), самолётик
  (квадрат 2×2) с «умным» наведением на цели уровня; все 10 клеток матрицы комбинаций; цепочки
  срабатываний, разрешаемые волнами.
- **Ящики** — обычный, цветной, меняющий цвет каждый ход, неразрушимый блокер, несколько жизней и
  вложенность до глубины 3. Описываются **данными** (оси `ElementDefinition` + правила источника
  урона), а не enum-ом: добавление льда/цепи/лозы не меняет ни строки в `Match3.Resolve`.
- **Цели** — сбор фишек цвета, бустеров или ящиков; несколько целей на уровень, порядок = и
  отображение, и приоритет наведения.
- **Уровни и поток** — 12 ассетов уровней плюс каталог, лимит ходов на уровень, победа → следующий
  уровень, поражение → переигровка, прогресс сохраняется в PlayerPrefs.
- **Читы** — переход на уровень, выиграть, проиграть, +5 ходов, поставить любой бустер в клетку,
  показ/применение seed попытки, бесплатные ходы, оверлей координат, показать подсказку / выключить
  подсказки. Только экранные элементы, без горячих клавиш; окно перетаскивается.
- **Презентация** — пулинг вью, FX уничтожения доигрывают до начала опадания, FX бустеров и
  комбинаций, HUD с целями и попапами, звуковые эффекты.

## Архитектура за минуту

- **Ход считается синхронно и целиком**, затем отдаётся презентации как упорядоченный *транскрипт*
  событий. Модель не ждёт анимаций; view во время проигрывания хода не мутирует и даже не читает поле.
- **`Modules/*` — чистый C#** (`noEngineReferences`): правила тестируются без Unity и без сцены.
  `Features/*` — презентация, HUD, прогрессия, читы; `Bootstrap` — композиция на Zenject. `Modules`
  никогда не ссылаются на `Features`.
- **Детерминизм** — один инжектируемый `IRandom` на попытку уровня, фиксированный порядок
  потребления. Тот же seed и те же вводы ⇒ идентичные хеши поля, это проверяет харнесс реплея.
- **Пайплайн RESOLVE** — DETECT → CLASSIFY → SPAWN → ACTIVATE → DAMAGE → CLEAR → ANIMATE → GRAVITY →
  REFILL → каскад, затем POST-TURN (препятствия по ходам, цели, ходы, перемешивание).
- **Ограничения WebGL** — однопоточность: никаких потоков, блокировок на async и time-операторов R3;
  время — только UniTask или DOTween. Никаких `Instantiate` и LINQ в горячем пути.

## Формат уровня

`LevelConfig` (ScriptableObject) → `LevelData` (чистый DTO) → `BoardBuilder` → `Board`. Тесты строят
уровни из строковой раскладки, без ассетов и сцены.

Токен = 2 символа, разделитель — пробел, первая строка — верхняя:

```
..  случайная фишка     t1..t6  фишка заданного цвета   __  дырка        ##  блокер
bx  ящик (1 hp)         b2 / b3 ящик на 2 / 3 жизни
c1..c6  цветной ящик    cx  ящик, меняющий цвет         rh / rv  ракета
bm  бомба               rb  радужный шар                pl  самолётик
```

Вложенность в сетке не пишется — она перечисляется по координатам в `contents`. Каждый уровень
валидируется на загрузке: размеры, известные токены, достижимость клеток от спавнеров, отсутствие
готовых матчей, наличие легального хода, достижимость целей, глубина вложенности ≤ 3.

## Тесты

Edit-mode тесты над чистыми модулями покрывают матчи, гравитацию, урон, вложенность, бустеры, всю
матрицу комбинаций, цепочки, цели, цикл хода, перемешивание, подсказки, парсинг и валидацию уровней,
реплей на детерминизм и прогон жадного бота по всем 12 уровням со сверкой winrate. В play-mode — один
smoke-тест (Boot → Game, уровень строится, скриптованный свап, попап победы).

Запуск через `Window > General > Test Runner` либо headless:

```
Unity.exe -batchmode -projectPath match3-test -runTests -testPlatform EditMode -testResults results.xml
```
